# Archaeological Site Prediction System

This project uses Machine Learning to predict the probability of archaeological sites based on geospatial features.

## Features
- Distance from Nile
- Elevation

## Tech Used
- Python
- Scikit-learn
- Streamlit

## How to Run
1. Train model:
   python model.py

2. Run app:
   streamlit run app.py
   or visit https://archaeological-site-predictor-2rkaczxxmgfpuqe67ksmqn.streamlit.app/
